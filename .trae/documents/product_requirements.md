# TeenList 产品需求文档

## 项目概述

TeenList 是一个专注于8至18岁青少年创造者与团队的精选名录网站。采用纯前端实现，数据将通过JSON文件管理。

## 设计规范

### 整体风格

* **设计理念**: Cupertino风格，Apple式设计语言

* **主色调**: 背景 `#FBFBFD`，卡片 `#FFFFFF`

* **强调色**: `#0071e3` (Apple Blue) 或单色

* **字体**: Inter 系统无衬线字体

* **圆角**: `rounded-3xl` 或 `rounded-[2rem]`

* **阴影**: 柔和扩散阴影 `box-shadow: 0 8px 40px rgba(0,0,0,0.08)`

### 页面结构

#### 1. 头部 (Header)

* **Logo**: 左侧显示 "TeenList"

* **导航**: 居中显示导航链接

* **申请按钮**: 右侧药丸形状按钮

#### 2. 英雄区域 (Hero)

* **主标题**: "TeenList，塑造明天"

* **副标题**: 浅灰色描述文字

* **切换开关**: Teams/Individuals 分段控制器

#### 3. 内容区域

根据切换状态显示不同卡片：

##### Teams 卡片

* **容器**: 白色背景，`rounded-[2rem]`，内边距 `p-8`

* **Logo**: 左上角 `rounded-xl w-12 h-12`

* **标题**: `text-2xl font-bold`

* **描述**: 2-3行文字，`text-gray-500`

* **标签**: 药丸形状标签（如"AI"、"杭州"、"11-50人"）

* **操作**: "访问网站"链接带箭头图标

* **新闻动态**: 内嵌容器 `bg-gray-50 rounded-xl p-4 mt-6`，显示3条最近更新

* **底部**: 创始人头像+名字，右侧社交图标

##### Individuals 卡片

* **布局**: 垂直肖像风格

* **视觉**: 顶部大封面图或大头像

* **内容**: 姓名、角色、简介片段

* **标签**: 技能/兴趣标签

#### 4. 申请按钮

* **位置**: 固定在页面右下角

* **样式**: 圆形按钮，带悬浮效果

* **功能**: 点击显示申请表单弹窗

## 功能需求

### 核心功能

1. **Teams/Individuals 切换**: 使用分段控制器
2. **卡片展示**: 响应式网格布局
3. **搜索过滤**: 按标签、地区等筛选
4. **申请功能**: 表单弹窗收集信息
5. **响应式设计**: 移动端适配

### 交互细节

* 平滑过渡动画

* 悬浮状态反馈

* 点击反馈

* 加载状态

## 数据管理

* 使用JSON文件存储数据

* Teams数据和Individuals数据分开管理

* 支持通过文件直接更新内容

## 技术实现

* **框架**: React + TypeScript

* **样式**: Tailwind CSS

* **图标**: Lucide React

* **状态管理**: Zustand

* **路由**: React Router

## 文件结构

```
src/
├── components/          # 组件
│   ├── Header.tsx      # 头部组件
│   ├── Hero.tsx        # 英雄区域
│   ├── ToggleSwitch.tsx # 切换开关
│   ├── TeamCard.tsx    # 团队卡片
│   ├── IndividualCard.tsx # 个人卡片

├── data/               # 数据文件
│   ├── teams.json      # 团队数据
│   └── individuals.json # 个人数据
├── pages/              # 页面
│   └── Home.tsx        # 主页
├── hooks/              # 自定义钩子
├── utils/              # 工具函数
└── types/              # 类型定义
```
